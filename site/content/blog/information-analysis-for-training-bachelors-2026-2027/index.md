## Programme

### Module 1: Data science in sport

- **Data sources and variables.** Heart rate readings, GPS tracks and athletes’ own reports illustrate biometric, movement and subjective data. Tables organise these observations for analysis. The course distinguishes qualitative and quantitative variables and nominal, ordinal, interval and ratio scales: a finishing position gives a rank, while finish times show the gap between runners.
- **Sampling and privacy.** A census covers the whole population; a sample may leave some groups underrepresented. GPS tracks illustrate a different limit on the use of data: sharing a route can reveal private locations.

### Module 2: Data representation and management

- **Storage and formats.** Files, folders, paths and metadata help locate and interpret records. CSV organises data in rows and columns. JSON and XML allow nested values; GPX uses XML to store GPS tracks. Free text is unstructured.
- **Digital representation.** Character sets and encodings represent text using bits and bytes. Examples include ASCII and Unicode. Raster images store pixels, while vector graphics describe shapes. Sampling rate and bit depth affect recorded sound; frame rate affects recorded video.
- **Sensor records.** Units identify what a value measures, sampling rate tells us how often a device records it, and timestamps let us align measurements from different devices during the same training session.

### Module 3: Data analysis with Microsoft Excel

- **Preparing data.** Power Query imports CSV files into Excel. Setting column types and checking dates and decimal separators keeps measurements usable. Tables, sorting and filters help select records for comparison.
- **Formulas and references.** Relative, absolute and mixed cell references control what changes when a formula is copied. Dividing total weight lifted by body weight gives one way to compare lifters of different sizes.
- **Summary statistics.** Counts, means, minima, maxima and standard deviation describe a group. Functions such as IF, COUNTIF and AVERAGEIF classify results and compare athletes within a category.
- **Charts and interpretation.** A line chart shows daily changes in calories burned. A scatter plot shows how average marathon finish time varies with age. The number of runners at each age matters when interpreting that average.
