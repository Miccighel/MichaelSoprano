## About this edition

I plan to focus on how the parts of a web application work together. When someone submits a form, the browser collects the input, the server checks it, and the database stores it for later use.

- **Degree:** Master's Degree in Management Engineering, University of Udine
- **Course:** *Applicazioni Web*
- **Instructor:** Michael Soprano
- **Workload:** 24 lectures (48 teaching hours)

[Course in the Uniud Course Catalogue](https://uniud.coursecatalogue.cineca.it/corsi/2026/10952/insegnamenti/2026/19639/2026/1?schemaid=13861#1)

## Programme

The detailed programme for 2026/2027 is being finalised. The main topics are expected to remain the same:

- **Web communication.** Read the HTTP request a browser sends and the response it receives. Use URLs to identify resources and JSON to exchange data.
- **Interfaces.** Structure pages and forms with HTML, adapt their layout with CSS and use JavaScript to respond to input without reloading the page.
- **Server and storage.** Define routes in Express to read and change records. Use SQLite to keep those records after the server restarts.

The [2025/2026 edition](/post/web-applications/2025-2026/) gives examples of exercises and a project from the previous year.

## Assessment

Students design and build a web application, then discuss how it works and explain their design choices.
