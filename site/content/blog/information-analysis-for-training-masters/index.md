## About the course

How can we record every training session without entering the athlete’s details again? This course uses examples from sport to show how to organise related records, keep them consistent and use SQL to answer questions about training and competition.

The course is taught in Italian under the title *Sistemi di Analisi ed Elaborazione delle Informazioni per l’Allenamento*. It is part of the integrated course *Discipline Motorie 1*.

## Teaching

I teach the course over 24 hours. I ask students to decide what a database needs to record before they create tables or write queries. That means checking the data, drawing a model and testing whether the design can represent the cases that matter.

## Programme

- **Working with sport data.** Identify what each record represents and check units, missing values and duplicates. Some editions also cover how to test predictions using data the model has not seen during training.
- **Relational database design.** Draw an entity and relationship diagram to show what needs to be stored and how records are connected. Turn the diagram into tables with primary and foreign keys. Use normalisation to avoid storing the same fact in several places.
- **Managing and querying a database.** Create tables and define rules for the values they can store. Use DBeaver to work with a SQLite database, then use SQL to filter, join and group records.

## Examples of practical work

- **Reporting cycling results.** In [2025/2026](/post/information-analysis-for-training-masters/2025-2026/#programme), students used the *Pedale Udinese* database to count distinct riders per race and produce a report that also included races outside a competition.
- **Modelling a football championship.** In [2026/2027](/post/information-analysis-for-training-masters/2026-2027/#programme), the design example uses a separate table for match appearances. It records minutes played for a player in a specific match, without repeating the player’s details.

## Materials
