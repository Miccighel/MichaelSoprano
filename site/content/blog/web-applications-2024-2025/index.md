## About this edition

Michael Soprano was the course instructor for the Master's Degree in Management Engineering at the University of Udine. The course comprised 24 lectures (48 hours); assessment was based on a full-stack project and discussion.

## Programme

The final programme summary presented at the end of the course covered:

1. **The Web and HTTP:** Web architecture, addressing and user agents; the client-server model; request and response structure, methods, headers, status codes and stateless communication.
2. **Resources and APIs:** URIs, URLs, URNs and query strings; requests with cURL, API testing with Postman, JSON data exchange and parameter encoding.
3. **HTML and forms:** document structure and semantics; text, lists, tables, links and embedded media; form controls, grouping and client-side validation.
4. **CSS and JavaScript:** selectors, the cascade, the box model and responsive layouts with Flexbox; DOM manipulation, event handling and avoiding cross-site scripting vulnerabilities.
5. **Express.js and persistence:** serving static files, defining routes, using middleware and storing data in SQLite.

The [course overview](/post/web-applications/) provides the broader context. The lecture slides for this year are not published on the site.
